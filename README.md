# AlairaX — Field Shift (NASA Space Apps 2026, Guanacaste, Costa Rica)

Simulador explicable que compara tres rotaciones (`rice_melon`, `rice_legume`, `rice_sorghum`) bajo el mismo clima histórico, sin predecir cosechas ni demostrar ahorro de agua.

## Cómo correr el backend

Requisitos: Python 3.11+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -e "backend[dev]"

cd backend
pytest
```
